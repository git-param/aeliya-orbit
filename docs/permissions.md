# Permissions & Organization Structure

## Core Concepts
- **Roles:** System access levels (Admin, HR, Manager, Employee).
- **Designations:** Job titles.
- **Departments:** Functional groups.
- **Reporting:** Hierarchical manager-employee relationships.
