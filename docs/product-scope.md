# Aeliya Orbit: Product Scope

## Initial Demo Target (3 Months)
- Target Audience: ~60 employees (scaling to 200-500).
- Modules Included: Employees, Org Structure, Permissions, Leave, Attendance, Breaks, Holidays, Complaints, Payroll, Notifications.
- Objective: Provide a fully functional, localized HR portal for Aeliya to replace manual processes.
